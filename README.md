# 🚀 تطبيق منظّم (Munazzim) - نظام إدارة الوقت الذكي

نظام متكامل لإدارة المهام والمواعيد الشخصية، مصمم لرفع الإنتاجية باستخدام تقنيات الذكاء الاصطناعي الواعي بالسياق، تم تطويره وفق معايير الجاهزية التقنية (NASA TRL).

**آخر تحديث:** الثلاثاء، 4 مارس 2025

## 💡 رؤية المشروع
يهدف "منظّم" إلى تحويل إدارة الوقت من مجرد تسجيل بيانات إلى عملية ذكية تفاعلية، حيث يقوم النظام بتحليل الروابط بين المهام والمواعيد لتقديم استشارات تنظيمية مخصصة لكل مستخدم بناءً على بياناته الحقيقية.

## ✨ المميزات الرئيسية
- **تحليل البيانات الذكي:** مساعد رقمي يحلل جدولك الحالي ويقدم نصائح فورية وتنبيهات بالتعارضات.
- **إدارة شاملة:** تتبع كامل للمواعيد والمهام مع تحديد مستويات الأولوية (عالية، متوسطة، منخفضة).
- **مركز الإحصائيات:** رسوم بيانية تفاعلية توضح معدلات الإنجاز وتوزيع الوقت حسب الفئات.
- **واجهة عصرية:** تصميم يدعم اللغة العربية بالكامل (RTL) مع تجربة مستخدم سلسة واحترافية.
- **الموثوقية العالية:** نظام مراقبة مستمر لضمان استقرار كافة الخدمات المرتبطة.

## 🛠 التقنيات المستخدمة
- **الإطار البرمجي:** Next.js 15 (App Router)
- **الذكاء الاصطناعي:** Google Genkit & OpenRouter (Gemini Models)
- **قواعد البيانات:** Firebase Firestore
- **التصميم:** Tailwind CSS & Shadcn UI
- **البيئة التشغيلية:** Docker Containers
