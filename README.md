# 🚀 تطبيق منظّم (Munazzim) - إدارة الوقت بذكاء

تطبيق عصري متكامل لإدارة الوقت والمهام، مصمم لرفع الإنتاجية الشخصية باستخدام تقنيات الذكاء الاصطناعي الواعي بالسياق. تم بناء النظام وفق معايير هندسية صارمة تتماشى مع مستويات الجاهزية التقنية (NASA TRL).

## 💡 فكرة المشروع
"منظّم" ليس مجرد قائمة مهام عادية، بل هو مساعد رقمي يفهم طبيعة يومك. يقوم النظام بربط جدول مواعيدك بمهامك اليومية ويستخدم الذكاء الاصطناعي لتحليل هذا الترابط، واكتشاف التعارضات، وتقديم نصائح مخصصة لتحسين الأداء بناءً على بيانات حقيقية.

## ✨ المميزات الرئيسية
- **لوحة تحكم ذكية (Dashboard):** عرض فوري لإحصائيات الإنجاز، كفاءة العمل، والمواعيد القادمة.
- **المساعد السياقي (AI Assistant):** مساعد ذكي يقرأ بياناتك (المواعيد والمهام) ويقدم استشارات تنظيمية دقيقة.
- **إدارة المواعيد والمهام:** نظام متكامل لإضافة وتتبع المهام مع تحديد الأولويات (عالية، متوسطة، منخفضة).
- **مركز الإحصائيات (Analytics):** رسوم بيانية متقدمة (Pie & Bar Charts) لتحليل توزيع الوقت ونسب الإنجاز.
- **سجلات النشاط (Activity Logs):** تتبع كامل لكل العمليات التي تتم داخل النظام لضمان الشفافية.
- **دعم اللغة العربية:** واجهة مستخدم كاملة تدعم الاتجاه من اليمين لليسار (RTL) بتصميم عصري.

## 🛠 الخصائص التقنية
- **Framework:** Next.js 15 (App Router)
- **UI Components:** Shadcn UI & Tailwind CSS
- **Database & Auth:** Firebase (Firestore & Authentication)
- **Generative AI:** Google Genkit with OpenRouter (Gemini/GPT Models)
- **Deployment:** Dockerized for High Availability
- **Monitoring:** Integrated Health Check API for system reliability
