# 🚀 منظّم (Munazzim) - المساعد الذكي لإدارة الوقت والإنتاجية

تطبيق **"منظّم"** ليس مجرد أداة لجدولة المواعيد، بل هو بيئة عمل متكاملة تعتمد على الذكاء الاصطناعي لإعادة صياغة علاقتك مع الوقت. تم تطوير هذا المشروع ليكون الرفيق الرقمي الذي يفكر معك، ينظم أولوياتك، ويحل تعارضاتك اليومية بذكاء وهدوء.

## 🌟 الرؤية والأهداف
في عصر التسارع الرقمي، أصبح تشتت الانتباه هو التحدي الأكبر. يهدف "منظّم" إلى تبسيط إدارة المهام من خلال واجهة عربية عصرية (RTL) تدمج بين بساطة التصميم وقوة المحركات الذكية (GenAI)، مما يساعد المستخدم على التركيز على ما يهم حقاً.

---

## 🛠 المميزات الرئيسية بالتفصيل

### 1. لوحة التحكم الذكية (Smart Dashboard)
عرض حي وفوري لكافة إحصائيات يومك. لا مزيد من الأرقام الجامدة؛ لوحة التحكم مرتبطة بذاكرة التطبيق لتحدث الأرقام (المواعيد، المهام، التنبيهات) فور إضافتها في أي قسم آخر.

### 2. مساعد منظّم الذكي (AI Assistant)
مدعوم بنماذج لغوية ضخمة عبر إطار عمل **Google Genkit**. يمكنك التحدث مع "منظّم" باللغة العربية الطبيعية:
- *مثال:* "عندي اجتماع الساعة 10 الصبح وموعد أسنان 10:30، كيف أرتبهم؟"
- سيقوم المساعد بتحليل التعارض، واقتراح حلول منطقية، وإعادة ترتيب أولوياتك بناءً على سياقك الشخصي.

### 3. نظام إدارة المواعيد (Appointment Engine)
نظام مرن يتيح لك إضافة وتعديل المواعيد مع تصنيفات ذكية (عمل، صحة، اجتماعي). يتم تخزين البيانات محلياً لضمان السرعة والخصوصية في هذه النسخة.

### 4. تعقب المهام المتقدم (Task Tracker)
نظام مهام يعتمد على مصفوفة الأولويات. يمكنك تحديد المهام العاجلة (High Priority) والتي تظهر فوراً كتنبيهات حمراء في لوحة التحكم لضمان عدم نسيانها.

### 5. مركز الإحصائيات (Productivity Analytics)
رسوم بيانية تفاعلية باستخدام مكتبة **Recharts** تحلل أداءك الأسبوعي وتوضح لك أين يذهب وقتك، مما يساعدك على اتخاذ قرارات أفضل لتحسين إنتاجيتك.

## 💻 المكدس التقني (Tech Stack)

تم بناء التطبيق باستخدام أحدث التقنيات لضمان الأداء والاستقرار:

*   **Next.js 15 (App Router):** لضمان أداء فائق وسرعة في التنقل بين الصفحات.
*   **Tailwind CSS & ShadCN UI:** لتصميم واجهة مستخدم احترافية، متجاوبة تماماً، وداعمة للغة العربية بشكل طبيعي.
*   **Google Genkit:** الإطار العملي لدمج الذكاء الاصطناعي التوليدي بسلاسة.
*   **OpenRouter / Gemini:** كنماذج ذكاء اصطناعي خلفية لمعالجة اللغة الطبيعية.
*   **Lucide React:** لمجموعة الأيقونات العصرية والمتناسقة.

## 🚀 كيفية البدء والتشغيل

### المتطلبات الأساسية
- Node.js 18+ 
- مفتاح API من OpenRouter أو Google AI Studio.

### خطوات التشغيل المحلي
1. قم بتحميل المستودع:
   ```bash
   git clone <repository-url>
   ```
2. تثبيت المكتبات:
   ```bash
   npm install
   ```
3. إعداد متغيرات البيئة:
   قم بإنشاء ملف `.env` وأضف مفتاح الـ API الخاص بك:
   ```env
   OPENROUTER_API_KEY=your_key_here
   ```
4. تشغيل المشروع:
   ```bash
   npm run dev
   ```
