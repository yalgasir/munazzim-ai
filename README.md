# 🚀 منظّم (Munazzim) - الإصدار الاحترافي الكامل (TRL 8)

تطبيق **"منظّم"** هو نظام متكامل لإدارة الوقت والإنتاجية تم ترقيته إلى مستوى الجاهزية الثامن (TRL 8)، حيث تم الانتقال من مجرد نموذج أولي إلى نظام برمجي مؤهل للاستخدام الفعلي، مدعوم بتقنيات **Genkit** ومبني على أسس هندسية متينة.

## 📊 حالة المشروع (TRL 8 Status)
وصل المشروع حالياً إلى مرحلة **System Complete and Qualified**، والتي تتضمن:
- **تكامل البيانات:** ربط حي وشامل بين لوحة التحكم، المواعيد، والمهام.
- **الذكاء الاصطناعي السياقي:** المساعد الذكي يحلل جدول المستخدم الفعلي لتقديم نصائح مخصصة.
- **الأمن والخصوصية:** نظام مصادقة (Authentication) مع عزل تام لبيانات كل مستخدم.
- **جاهزية النشر:** دعم كامل للحاويات (Docker) والمزامنة السحابية.

## 🛠 المزايا التقنية المتقدمة

### 1. محرك التحليلات الديناميكي
نظام معالجة بيانات حي يقرأ من قاعدة بيانات Firestore أو التخزين المحلي، ويقوم بتوليد رسوم بيانية تفاعلية تعكس أداء المستخدم الحقيقي وتساعده في اتخاذ قرارات أفضل بشأن وقته.

### 2. المساعد الذكي (AI Scheduler Optimizer)
باستخدام **Google Genkit** ونموذج **Gemini 1.5 Flash**، يقوم المساعد بـ:
- اكتشاف التعارضات الزمنية تلقائياً.
- اقتراح إعادة ترتيب الأولويات بناءً على كثافة الجدول.
- تقديم "رؤية يومية" ملخصة تساعد في تقليل الإجهاد الذهني.

### 3. هندسة الواجهة (UI/UX Excellence)
- واجهة تدعم الـ RTL بشكل كامل (العربية).
- نظام سمات (Themes) متطور يعتمد على HSL.
- تجربة مستخدم سلسة مع حالات تحميل (Loading States) ومعالجة أخطاء ذكية.

## 💻 المكدس التقني (Tech Stack)
*   **الإطار العملي:** Next.js 15 (App Router)
*   **قاعدة البيانات:** Firebase Firestore / LocalStorage Fallback
*   **الذكاء الاصطناعي:** Google Genkit AI Studio
*   **الواجهة:** Tailwind CSS & ShadCN UI
*   **الرسوم البيانية:** Recharts API

## 🚀 التشغيل والنشر
المشروع جاهز للعمل فوراً عبر Docker:
```bash
docker build -t munazzim-app .
docker run -p 3000:3000 munazzim-app
```
