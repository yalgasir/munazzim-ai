# 🚀 تطبيق منظّم (Munazzim) - نظام إدارة الوقت الذكي

نظام متكامل لإدارة المهام والمواعيد الشخصية، مصمم لرفع الإنتاجية باستخدام تقنيات الذكاء الاصطناعي الواعي بالسياق (Gemini 1.5 Engine)، تم تطويره وفق معايير الجاهزية التقنية (NASA TRL).

**آخر تحديث:** الثلاثاء، 4 مارس 2025

## 💡 رؤية المشروع
يهدف "منظّم" إلى تحويل إدارة الوقت من مجرد تسجيل بيانات إلى عملية ذكية تفاعلية، حيث يقوم النظام بتحليل الروابط بين المهام والمواعيد لتقديم استشارات تنظيمية مخصصة لكل مستخدم بناءً على بياناته الحقيقية.

## ✨ المميزات الرئيسية
- **محرك Gemini 1.5 Pro:** تحليل البيانات السياقية العميقة لتقديم نصائح دقيقة وتجنب تعارض المواعيد.
- **الوصول العام (Public Access):** تجربة مستخدم سلسة تتيح الدخول المباشر دون الحاجة لعمليات تسجيل معقدة.
- **مختبر الاختبارات (Testing Suite):** بيئة اختبارات برمجية (TRL 4) لضمان موثوقية الخوارزميات.
- **مركز الإحصائيات (TRL 8):** لوحة بيانات حية تعرض معدلات الإنجاز وكفاءة تنظيم الوقت.
- **واجهة عصرية:** تصميم يدعم اللغة العربية بالكامل (RTL) مع تجربة مستخدم احترافية.

## 🛠 التقنيات المستخدمة
- **الإطار البرمجي:** Next.js 15 (App Router)
- **الذكاء الاصطناعي:** Google Genkit & Gemini 1.5 Pro
- **قواعد البيانات:** Firebase Firestore
- **التصميم:** Tailwind CSS & Shadcn UI
- **الاختبارات:** Custom Testing Suite (NASA TRL 4 Standards)
