# 🚀 تطبيق منظّم (Munazzim) - نظام إدارة الوقت الذكي

تطبيق "منظّم" هو الحل المتكامل لإدارة المهام والمواعيد، تم تطويره ورفعه إلى مستوى الجاهزية التقنية **NASA TRL 8**. يعتمد التطبيق كلياً على محرك **MythoMax-L2-13B** لتقديم استشارات ذكية ودقيقة.

**آخر تحديث:** 4 مارس 2025 (الإصدار v1.0.0-PRO)

## 💡 الرؤية
التحول من مجرد تسجيل المهام إلى الإدارة الواعية للوقت باستخدام الذكاء الاصطناعي السيادي.

## ✨ المميزات الرئيسية
- **محرك MythoMax L2 13B:** تحليل المواعيد وتقديم استشارات سياقية عميقة باللغة العربية الفصحى.
- **تكامل NASA TRL 8:** نظام مكتمل ومؤهل تقنياً وفق المعايير الدولية.
- **خصوصية فائقة:** خيارات الوصول العام مع حفظ البيانات محلياً أو سحابياً بشكل آمن.
- **مركز تحليلات متقدم:** لوحة إحصائيات حية تتبع معدلات الإنجاز لحظياً.

## 🛠 التقنيات الهندسية
- **Framework:** Next.js 15 (App Router).
- **AI Engine:** Gryphe MythoMax-L2-13B (OpenRouter).
- **Database:** Firebase Firestore.
- **Styling:** Tailwind CSS & Shadcn UI.
- **Quality:** NASA TRL Engineering Standards.
