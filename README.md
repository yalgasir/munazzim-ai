# 🚀 تطبيق منظّم (Munazzim) - نظام إدارة الوقت الذكي

نظام متكامل لإدارة المهام والمواعيد الشخصية، مصمم لرفع الإنتاجية باستخدام تقنيات الذكاء الاصطناعي الواعي بالسياق، تم تطويره وفق معايير الجاهزية التقنية (NASA TRL).

## 💡 رؤية المشروع
يهدف "منظّم" إلى تحويل إدارة الوقت من مجرد تسجيل بيانات إلى عملية ذكية تفاعلية، حيث يقوم النظام بتحليل الروابط بين المهام والمواعيد لتقديم استشارات تنظيمية مخصصة لكل مستخدم.

## ✨ المميزات الرئيسية
- **تحليل البيانات الذكي:** مساعد رقمي يحلل جدولك الحالي ويقدم نصائح فورية.
- **إدارة شاملة:** تتبع كامل للمواعيد والمهام مع تحديد مستويات الأولوية.
- **مركز الإحصائيات:** رسوم بيانية توضح معدلات الإنجاز وتوزيع الوقت.
- **واجهة عصرية:** تصميم يدعم اللغة العربية بالكامل (RTL) مع تجربة مستخدم سلسة.
- **الموثوقية العالية:** نظام مراقبة مستمر لضمان استقرار الخدمات (Health Check).

## 🛠 التقنيات المستخدمة
- **الإطار البرمجي:** Next.js 15
- **الذكاء الاصطناعي:** Google Genkit & OpenRouter
- **قواعد البيانات:** Firebase Firestore
- **التصميم:** Tailwind CSS & Shadcn UI
- **البيئة التشغيلية:** Docker Containers
