# 🚀 منظّم (Munazzim) - المساعد الذكي لإدارة الوقت والإنتاجية

تطبيق **"منظّم"** هو بيئة عمل متكاملة تعتمد على تقنيات الذكاء الاصطناعي التوليدي لإعادة صياغة علاقتك مع الوقت. تم تطوير هذا المشروع ليكون الرفيق الرقمي الذي يفكر معك، ينظم أولوياتك، ويحل تعارضاتك اليومية بذكاء وهدوء، مع واجهة مستخدم عربية عصرية تدعم القراءة من اليمين إلى اليسار (RTL).

## 🌟 الرؤية والأهداف الإستراتيجية
في ظل التسارع الرقمي الهائل، أصبح "تشتت الانتباه" هو العائق الأكبر أمام الإنجاز. يهدف "منظّم" إلى تقليل الجهد الذهني المبذول في التخطيط من خلال:
- **الأتمتة الذكية:** تحويل النصوص العادية إلى مواعيد منظمة.
- **التحليل الاستباقي:** اكتشاف التعارضات في الجدول الزمني قبل وقوعها.
- **التوجيه المخصص:** تقديم نصائح لزيادة الإنتاجية بناءً على سياق يوم المستخدم.

## 🛠 المميزات الرئيسية بالتفصيل

### 1. لوحة التحكم الذكية (Smart Dynamic Dashboard)
ليست مجرد عرض للأرقام، بل هي "عقل" التطبيق:
- **مزامنة حية:** ترتبط لوحة التحكم بذاكرة المتصفح (LocalStorage)، مما يعني أن أي تغيير في المواعيد أو المهام يظهر أثره فوراً في الإحصائيات (مواعيد اليوم، المهام المعلقة، التنبيهات العاجلة).
- **نظام التنبيهات:** تبرز المهام ذات الأولوية العالية (High Priority) فوراً في قسم التنبيهات لضمان عدم نسيانها.

### 2. مساعد منظّم الذكي (GenAI Assistant)
مدعوم بأحدث تقنيات **Google Genkit** ونماذج اللغة الضخمة:
- **فهم اللغة الطبيعية:** يمكنك كتابة "عندي اجتماع الساعة 10 الصبح وموعد أسنان 10:30" وسيقوم المساعد بتحليل التعارض واقتراح حلول.
- **تحسين الجداول:** يمتلك المساعد القدرة على إعادة ترتيب أولوياتك بذكاء مهني.

### 3. محرك إدارة المواعيد (Appointment Engine)
نظام مرن يتيح إدارة كاملة للمواعيد:
- إضافة، تعديل، وحذف المواعيد.
- تصنيفات ذكية (عمل، صحة، اجتماعي، تعليم).
- تخزين آمن وسريع يضمن الخصوصية الكاملة للمستخدم.

### 4. تعقب المهام المتقدم (Task Management System)
نظام مهام يعتمد على مصفوفة الأولويات:
- تحديد درجة الأهمية (عالية، متوسطة، منخفضة).
- تتبع حالة الإنجاز بصرياً مع تأثيرات حركية سلسة.
- ربط مباشر مع لوحة التحكم لإظهار المهام الأكثر إلحاحاً.

### 5. مركز التحليلات والبيانات (Productivity Analytics)
باستخدام مكتبة **Recharts** المتطورة:
- رسوم بيانية تفاعلية تحلل الأداء الأسبوعي.
- توزيع المهام حسب الفئات لفهم أين يذهب الوقت.
- إحصائيات تراكمية تساعد في تحسين العادات اليومية.

## 💻 المكدس التقني (Advanced Tech Stack)

تم بناء التطبيق باستخدام أحدث المعايير في تطوير الويب:

*   **Next.js 15 (App Router):** لضمان أداء فائق وسرعة تنقل بين الصفحات مع دعم كامل للـ Server Components.
*   **Tailwind CSS & ShadCN UI:** لتصميم واجهة مستخدم احترافية، متجاوبة تماماً مع كافة الشاشات، وتدعم النظام الداكن (Dark Mode).
*   **Google Genkit:** الإطار العملي المتطور لدمج الذكاء الاصطناعي التوليدي بسلاسة داخل الكود.
*   **Firebase & Firestore:** جاهزية تامة للربط مع قواعد البيانات السحابية للمزامنة بين الأجهزة.
*   **Lucide React:** لمجموعة الأيقونات العصرية والمتناسقة التي تعزز تجربة المستخدم.

## 🚀 كيفية البدء والتشغيل (للمطورين)

### المتطلبات الأساسية
- Node.js 18 أو أحدث.
- مفتاح API صالح من Google AI Studio أو OpenRouter.

### خطوات التشغيل المحلي
1. **تحميل المستودع:**
   ```bash
   git clone <repository-url>
   ```
2. **تثبيت المكتبات:**
   ```bash
   npm install
   ```
3. **إعداد البيئة:**
   قم بإنشاء ملف `.env` وأضف المفتاح الخاص بك:
   ```env
   OPENROUTER_API_KEY=your_key_here
   ```
4. **تشغيل التطبيق:**
   ```bash
   npm run dev
   ```
