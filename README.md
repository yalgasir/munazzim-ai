# منظّم | Munazzim - المساعد الذكي لإدارة الوقت

تطبيق "منظّم" هو منصة عصرية متكاملة لإدارة الوقت والمهام، مصمم خصيصاً لرفع الإنتاجية الفردية باستخدام تقنيات الذكاء الاصطناعي. يتميز التطبيق بواجهة مستخدم عربية بالكامل (RTL) وتصميم عصري يجمع بين البساطة والقوة.

## 🚀 المميزات الرئيسية

*   **لوحة تحكم ذكية (Dashboard):** عرض فوري لإحصائيات اليوم، المواعيد القريبة، والمهام العاجلة ببيانات حية تتحدث تلقائياً بناءً على مدخلاتك.
*   **مساعد منظّم الذكي (AI Assistant):** مساعد يعتمد على نماذج اللغة الكبيرة لتحليل جدولك الزمني، حل التعارضات، وتقديم نصائح مخصصة لتحسين إنتاجيتك.
*   **إدارة المواعيد (Appointments):** نظام مرن لإضافة ومتابعة المواعيد مع واجهة سهلة الاستخدام وتصنيف ذكي.
*   **نظام المهام (Task Management):** تتبع المهام اليومية مع تحديد الأولويات (عالية، متوسطة، منخفضة) ومتابعة حالة الإنجاز.
*   **إحصائيات متقدمة (Analytics):** رسوم بيانية تفاعلية تحلل أدائك الأسبوعي وتوزع وقتك حسب الفئات المختلفة.

## 🛠 التقنيات المستخدمة

*   **Framework:** Next.js 15 (App Router)
*   **UI Components:** ShadCN UI & Tailwind CSS
*   **AI Engine:** Google Genkit (Generative AI Framework)
*   **Charts:** Recharts
*   **Deployment:** Docker Ready
